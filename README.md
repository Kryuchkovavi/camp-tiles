## Camp Tiles — сайт бронирования мест в кемпинге

Тема проекта: разработка интерактивного сайта для выбора и бронирования мест в кемпинге.

Camp Tiles — учебный веб-проект, в котором пользователь может выбрать место для палатки на интерактивной карте, посмотреть его характеристики, указать даты отдыха и количество гостей, рассчитать стоимость и оформить бронирование. Перед бронированием пользователь может зарегистрироваться или войти в аккаунт, к которому привязываются его брони.

## Что работает

- 8 мест для палаток, у каждого есть ID, название, описание, вместимость, цена за ночь, координаты на схеме и статус занятости.
- Два участка изначально заняты.
- Схема и список строятся на основе одного массива данных.
- Выбор участка на схеме или в списке обновляет одну и ту же карточку.
- Фильтры по числу гостей (от 1 до 8), диапазону минимальной/максимальной цены и датам заезда/выезда одновременно обновляют карту и список.
- Расчёт стоимости: цена за ночь × количество ночей.
- Проверка количества гостей (от 1 до вместимости) и количества ночей (от 1 до 30).
- Подтверждение брони в диалоговом окне, уникальный номер, расчёт количества ночей по выбранным датам и защита от повторного бронирования участка на пересекающийся период. Один участок можно забронировать на разные, непересекающиеся даты.
- Раздел «Мои брони» и отмена брони с подтверждением.
- Регистрация и вход в локальный учебный аккаунт по имени, электронной почте и паролю; брони привязываются к ID аккаунта, а раздел «Мои брони» показывает брони вошедшего пользователя.
- Данные аккаунтов и бронирований сохраняются в `localStorage` под одним ключом `campTilesDemo_v1`.
- Кнопка сброса демо с подтверждением.
- Адаптивная вёрстка, видимый клавиатурный фокус, подписи полей и текстовые статусы — не только цвет.
- Анимация костра, бегущая строка, мерцающие звёзды по бокам страницы, за пределами основного контента и зелёный курсор со следом; анимации сокращаются при системной настройке reduced motion.
- Выбор участка не переносит сразу к форме бронирования: под картой и списком появляется отдельная кнопка перехода к брони.

## Ограничения

Это **учебное демо**. Аккаунты и брони хранятся только в `localStorage` текущего браузера на текущем устройстве. Регистрация не создаёт настоящий серверный аккаунт: нельзя войти с другого устройства, а очистка данных браузера удалит профиль и брони.

## Технологии

- HTML — структура и формы;
- CSS — адаптивная вёрстка, пиксельные детали и анимации;
- JavaScript ES-модули — данные, состояние, DOM, события, валидация;
- JSON и `localStorage` — сохранение учебных броней.

## Использование ИИ

При подготовке проекта использовался ИИ как помощник для разработки структуры, оформления, интерактивных элементов и проверки логики.

Примеры промптов:
1. «Создай сайт бронирования мест для палаток Camp Tiles на HTML, CSS и ванильном JavaScript, без фреймворков и сервера. Нужны карта, список из 8 участков, карточка выбранного участка и адаптивный пиксельный дизайн».
2. «Добавь фильтры по числу гостей и максимальной цене. Карта и список должны использовать один массив данных и обновляться одновременно. Занятые участки нельзя выбрать».
3. «Добавь регистрацию и вход в учебный аккаунт, привязку бронирований к пользователю, проверку формы, расчёт цены, подтверждение, отмену и сохранение в localStorage. Объясни ограничения без сервера и выдай порядок проверки».
